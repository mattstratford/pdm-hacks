## [Breadboarder](https://mattstratford.github.io/pdm-hacks/Breadboard.html)
Inspired by Ryan Singer's breadboard technique from [Shape Up](https://basecamp.com/shapeup/1.3-chapter-04), this is a widget in which you enter Markdown in the left pane and get a breadboard diagram in the right pane with "places" on top and "affordances" on the bottom of each notation unit. It saves and loads `.md` files. Built with Claude, so if you don't want AI-derived software then don't use it.
